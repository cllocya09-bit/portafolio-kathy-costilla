# Portafolio de Diseño Publicitario y Audiovisual

Portafolio profesional de **Khaterine Costilla Altamirano**: diseño publicitario, campañas comerciales, afiches y producción audiovisual.

Hecho con React, Vite y Tailwind CSS.

## Ejecutar en local

Requiere [Node.js](https://nodejs.org) 20 o superior.

```bash
npm install
npm run dev
```

Se abre en http://localhost:3000

## Compilar

```bash
npm run build     # genera la carpeta dist/
npm run preview   # previsualiza la versión compilada
```

## Publicación

Cada `git push` a la rama `main` publica el sitio automáticamente en GitHub Pages
(workflow en `.github/workflows/deploy.yml`).

Las imágenes están en `public/images/`.
